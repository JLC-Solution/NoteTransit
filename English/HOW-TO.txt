NOTETRANSIT: ONENOTE -> APPLE NOTES
===================================

Before you start
- A Mac signed in to the iCloud account that should receive the notes, with Notes
  turned on (System Settings > your name > iCloud > Notes).
- Your Microsoft account (the one with OneNote) and an internet connection.
- Mac plugged in, lid open: a large migration can take hours.

Running it
1. Open the Terminal app (Cmd+Space, type "Terminal", Enter).
   Type  bash  followed by a space (don't press Enter), drag the file
   "Start migration.command" into the window, then press Enter.
   (Double-clicking the file is blocked by macOS because it is not signed:
   if a warning appears, click Cancel, not Move to Trash.)
2. If Python is not installed, macOS offers to install the "command line
   developer tools": accept, wait until it finishes, then run it again.
3. The Terminal shows a link (https://login.microsoft.com/device) and a code:
   open the link, type the code, sign in with your Microsoft account.
4. Your notebooks are listed. Type the name of one, or press Enter for all.
   Answer "y" for a 3-page test, "n" to do everything.
5. The script takes inventory, then downloads every page. Nothing appears in
   Notes meanwhile: that's expected. Microsoft limits requests per hour, so
   there are pauses: let it run.
6. At the end, Notes asks "Import?": click Import (the window may be behind the
   Terminal). One click per batch of 500 notes.
7. If macOS asks to let "Terminal" control "Notes", click OK.
8. The script then files each note into the right folder.

Result
- An "Import OneNote" folder in Notes: notebook = folder, section = subfolder,
  page = note. Sub-pages are titled "Parent page › Sub-page".
- iCloud then syncs everything to your iPhone and iPad.

Interrupted? Just run it again: it resumes where it stopped.
Do NOT interrupt it during "Filing notes into folders…". If that happened:
delete the "Import OneNote" and "Imported Notes" folders in Notes and the
migration_state.json file, then run it again.

Kept: headings, bold/italic/underline, lists, checklists, tables, images (inline),
attachments, original creation and modification dates.
Not kept: ink and handwriting, colors and fonts, free-form layout (content becomes
a single column), checked state of checkboxes, notebooks shared by someone else.
OneNote is never modified: your original notes stay untouched.
